# Информационная система Автосалона

## 1. Название и краткое описание (Elevator Pitch)
Простое десктопное приложение (WPF) для автоматизации работы автосалона. Позволяет вести учет проданных автомобилей, оформлять новые сделки и разграничивать права доступа сотрудников.

## 2. Визуальная демонстрация (если применимо)
Проект представляет собой десктопное приложение с графическим интерфейсом. Визуально проект состоит из трех основных окон: окно авторизации, главное окно с таблицей продаж и окно оформления новой сделки.

## 3. Установка (Installation)
1. Клонируйте репозиторий.
2. Откройте решение в Visual Studio.
3. Установите пакет `Microsoft.Data.SqlClient` через NuGet.
4. Убедитесь, что база данных `AutoSalonDB` создана. Строка подключения настроена на локальную БД `(localdb)\MSSQLLocalDB`.

## 4. Использование (Usage)
1. Введите логин и пароль (например, `admin` / `123` или `user` / `123`).
2. В главном окне отображается таблица продаж.
3. Роли `Admin` и `Manager` могут нажать «Оформить продажу» и создать запись.
4. Роль `User` имеет доступ только к просмотру.

## 5. Структура проекта
- `MainWindow.xaml` — Окно авторизации.
- `DashboardWindow.xaml` — Главное окно (таблица и меню).
- `AddSaleWindow.xaml` — Окно оформления новой продажи.

## 6. Данные (Data)
База данных MS SQL Server `AutoSalonDB`. Основные таблицы: `Users`, `Sale`, `Car`, `Client`, `Employee`.
